### Max Saiets

I build software that measures things from video and turns documents into answers you can check. Several of these run in production.

<a href="https://github.com/MaxSaiets/jumpsight-code"><img src="https://raw.githubusercontent.com/MaxSaiets/jumpsight-code/main/docs/media/jump-analysis.gif" width="420" alt="JumpSight: what the system measures next to the original video"></a>

**[JumpSight](https://github.com/MaxSaiets/jumpsight-code)** counts revolutions and names figure-skating jumps from one phone video. Pose estimation, signal processing, a graph network for the jump type, and a rule that no number is shown unless it was measured.

**[3D Map Generator](https://github.com/MaxSaiets/3d-map-generator)** turns any area of OpenStreetMap into a multi-colour 3D model ready to print. Live service with paying customers.

**[Argus](https://github.com/MaxSaiets/argus-video-intelligence)** turns camera streams into events (crossings, occupancy, dwell) that can be searched in plain language.

**[Conductor](https://github.com/MaxSaiets/conductor-agent-orchestrator)** runs business workflows written in YAML on LangGraph, with side effects that happen exactly once even if a worker dies.

Also: [Aksan bot](https://github.com/MaxSaiets/Aksan_telegram_bot) and [Fish](https://github.com/MaxSaiets/Fish), automation built for two retail businesses.

Python, PyTorch, OpenCV, FastAPI, PostgreSQL, TypeScript, Next.js.
